# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, welcoming and patient. No harassment, personal attacks or discrimination.
Maintainers may edit or remove comments, issues and contributions that break these rules.

To report a problem, use the repository's private "Report a vulnerability / security advisory" form
or message the maintainer through their GitHub profile.
